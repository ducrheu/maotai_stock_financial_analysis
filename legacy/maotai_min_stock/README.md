# 贵州茅台1分钟级数据量化分析项目
## 项目简介
本项目是基于 Python + AKShare + PostgreSQL 的量化数据实战项目，完整实现 **A股分钟级数据获取 → 数据标准化清洗 → 数据库持久化存储 → 量化指标计算** 全流程，适用于量化学习、实习作品集参考。

项目全程使用免费开源工具，无付费接口，代码简洁易懂，适合金融工程、计算机专业学生学习。

---

## 核心功能
1. **数据获取**：通过 AKShare 免费获取贵州茅台（sh600519）1分钟K线数据
2. **数据清洗**：标准化列名、时间转换、去重、异常值过滤、交易时段筛选
3. **数据存储**：清洗后数据入库 PostgreSQL 数据库
4. **指标计算**：基于 SQL 窗口函数计算均线、涨跌幅、量比、振幅等核心量化指标

---

## 技术栈
- 数据采集：AKShare
- 数据处理：Pandas
- 数据库：PostgreSQL 14+
- 数据计算：SQL 窗口函数
- 开发语言：Python 3.8+
